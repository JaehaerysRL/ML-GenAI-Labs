## File Structure

Each course folder contains:
- Jupyter notebooks (.ipynb) for labs and assignments
- Course materials and notes
- Project files
- Individual README.md with course-specific information

## Getting Started

### Prerequisites

- Python 3.x
- Jupyter Notebook
- Common ML libraries (numpy, pandas, matplotlib, scikit-learn)

### Installation

```bash
pip install jupyter numpy pandas matplotlib scikit-learn
```

### Running Jupyter Notebooks

```bash
jupyter notebook
```
